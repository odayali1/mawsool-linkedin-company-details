# LinkedIn company details from a company URL

Send a LinkedIn company URL. You get the website, industry, size, headquarters, locations, specialties, and recent posts.

Starting from $0.90 per 1,000 companies.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-company-details. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You want the full company record from a URL you already have.

## When to use a different Actor

You only need the website, industry, and employee range. Use Firmographics. You have a person, not a company URL. Use Profile to Company Website.

Mawsool is not affiliated with LinkedIn.
