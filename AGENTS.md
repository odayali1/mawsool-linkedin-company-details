# LinkedIn Company Details

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-company-details` on Apify: https://apify.com/oday/mawsool-linkedin-company-details
- Send a LinkedIn company URL. You get the website, industry, size, headquarters, locations, specialties, and recent posts.
- Starting from $0.90 per 1,000 companies.
- Use it when: You want the full company record from a URL you already have.
- Use something else when: You only need the website, industry, and employee range. Use Firmographics. You have a person, not a company URL. Use Profile to Company Website.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.

## Do not assume

This Actor does not log into LinkedIn. Mawsool is not affiliated with LinkedIn.
